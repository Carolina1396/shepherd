# Follow-up experiments

Follow-ups answer questions raised by the main cross-environment experiment without changing its original forty-query evidence.

- [Rule-failure analysis](rule-failure-analysis/README.md) tracks systematic investigations of rules that Retriever rejected or that returned empty callbacks.
- [Development tier selection](development-tier-selection/README.md) tests omitted tier controls and an explicit Tier 1 request.

Each follow-up must distinguish saved observations from conclusions, link exact requests and responses, record the tested environments and graph release information, and identify remaining work.
