Blocker and resolution
Initially we used remote development Omnicorp explicitly through a hybrid
runner because local publication-count databases were missing.
The supplied individual shared_counts.lmdb download was 437,898,240 bytes,
while its embedded metadata referenced 9,060,515,840 bytes. Entity publication
lookups worked, but shared-pair reads caused SIGBUS. A full query reproduced it:
lookup returned 2 results, local enrichment crashed, HTTP 500, no scoring.
A directory listing revealed omnicorp_data_05_05_2026.tar.gz (2.68 GB compressed).
It contains the complete database. Extracted manually because the archive has
an enclosing directory, which the automatic downloader would retain.
Validated page bounds, backed up earlier files, and reused the existing worker
image without reinstalling or rebuilding. Startup validation guard remains
removed at user request; the validator is available manually.
